**Post:**

AI agents changed how fast we ship. They didn't change how we find out something broke.

A pattern that's easy to hit with Claude Code and Cursor:
✅ it compiles
✅ lint passes
✅ unit tests pass
❌ signup is broken, because the agent "tidied up" a file it wasn't asked to touch

Unit tests check functions. Nobody checks the flow a real user clicks through.

So I open-sourced stillworks. It runs your critical journeys (signup, login, checkout) in a real browser after each change. When something breaks, it writes a report your agent can fix from: the failed step, the server error, a screenshot.

It's free, MIT licensed, and works with Claude Code, Cursor, Codex and GitHub Actions.
